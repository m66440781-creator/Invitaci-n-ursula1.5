# Assets / Recursos

Este repositorio contiene la estructura del sitio para la "Invitación Úrsula 1.5". Los ficheros binarios (imágenes y audios) no se han incluido: por favor sube los archivos con estos nombres exactamente en las carpetas indicadas.

Carpeta img/ (colocar aquí las imágenes):
- ursula.png        ← imagen principal de la invitación (obligatoria)
- fondo.jpg         ← imagen de fondo (opcional)

Carpeta audio/ (colocar aquí los audios):
- musica.mp3        ← pista de música de fondo
- abrir.mp3         ← sonido que se reproduce al pulsar "Abrir"
- magia.mp3         ← efecto mágico corto
- confetti.mp3      ← sonido del confeti

Sugerencia de pasos para subir los assets:
1. Sube los archivos binarios exactamente con esos nombres en las carpetas img/ y audio/.
2. Si quieres que la música se reproduzca automáticamente en algunos navegadores, considera añadir controles o un botón claro para activar el audio por interacción del usuario.

Si prefieres que yo suba los binarios por ti, adjunta los archivos en un mensaje y los añadiré al repo.
